# Editorial Rules

- Prefer original titles. Do not invent claims that are absent from source data.
- News is optional and reserved for major F# language, compiler, tooling, or community announcements.
- Order Microsoft items by F# relevance, then general .NET relevance.
- Blogs should link to the article, not the social post that shared it.
- Select 2-5 highlighted projects that are new, active, released recently, or unusually relevant.
- Stable releases precede prereleases. Include a prerelease only when notable or above 10,000 total downloads.
- If `FSharp.Data` is included, omit `FSharp.Data.*` packages.
- Do not reuse an item already excluded by preparation as published recently.
- Bluesky embeds are optional. Select no more than three and do not block publication when unavailable.
